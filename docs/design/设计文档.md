# 系统设计文档

## 一、总体架构
采用前后端分离架构
- 前端：UI交互展示、页面路由、用户操作交互
- 后端：业务逻辑处理、接口提供、权限校验
- 数据库：MySQL 持久化存储全部业务数据

## 二、模块划分
1.  用户权限模块
2.  公会管理模块
3.  任务流程管理模块
4.  公告通知模块
5.  数据统计模块

## 三、数据库核心表设计
1.  user 用户表：账号、密码、角色、所属公会、状态
2.  guild 公会表：公会名称、创建人、简介
3.  task 任务表：任务标题、内容、截止时间、发布人、状态
4.  task_record 任务记录表：领取人、提交内容、审核结果
5.  notice 公告表：标题、内容、发布时间

## 四、核心业务流程
1.  管理员发布任务 → 用户浏览并领取 → 用户提交任务 → 管理员审核 → 任务完结
2.  全程状态自动流转，全程可追溯

## 五、部署设计
- 本地开发部署，可打包部署至服务器
- 配套SQL脚本一键初始化数据库
