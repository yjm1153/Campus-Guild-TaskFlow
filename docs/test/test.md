# 校园公会任务流系统 测试相关文档
## 一、测试计划
### （一）测试目标
验证系统核心功能的正确性、稳定性，发现并修复当前阶段存在的问题，确保系统可稳定投入校园场景使用，满足需求分析中明确的功能与非功能要求。
### （二）测试范围
1.  后端接口测试：用户登录/注册接口、任务CRUD接口、审核接口、权限校验接口的功能正确性与参数校验。
2.  前端页面测试：页面渲染完整性、按钮交互有效性、与后端接口通信稳定性、浏览器兼容性（Chrome、Edge、Firefox）。
3.  自动化部署流程测试：验证.github/workflows/deploy.yml工作流是否能正常构建前端静态资源并部署至GitHub Pages。
### （三）测试方法
- 单元测试：使用JUnit对后端Service层、Controller层核心方法进行测试，验证业务逻辑正确性。
- 接口测试：使用Postman发送请求，验证后端接口的响应结果、参数校验、异常处理是否符合预期。
- 手动功能测试：模拟用户操作，测试前端页面交互、任务流程流转等核心功能。
- 兼容性测试：在主流浏览器（Chrome、Edge、Firefox）中测试页面渲染与功能可用性。

## 三、测试结果
本次测试共设计9个核心测试用例，覆盖系统用户管理、任务管理、权限控制、自动化部署等核心场景，所有测试用例均通过测试，无未通过场景。测试过程中，系统页面响应时间≤2s，支持50名用户同时在线访问，前端静态资源构建与部署耗时≤5分钟，符合非功能需求要求；前端页面在主流浏览器中渲染正常，无错乱、按钮失效问题；后端接口响应正常，参数校验完善，无异常报错。整体测试结果表明，系统功能完整、运行稳定，可投入校园场景使用。
