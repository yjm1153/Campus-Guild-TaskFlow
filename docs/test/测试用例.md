# 测试用例

| 用例编号 | 测试功能 | 测试步骤 | 预期结果 | 实际结果 | 测试状态 |
| --- | --- | --- | --- | --- | --- |
| TC001 | 管理员账号登录 | 1.输入正确管理员账号密码 2.点击登录 | 成功进入管理员后台，展示全部管理菜单 | | |
| TC002 | 普通用户账号登录 | 1.输入普通账号密码 2.点击登录 | 成功进入普通用户首页，看不到管理功能 | | |
| TC003 | 错误密码登录 | 1.输入正确账号、错误密码 2.点击登录 | 提示账号或密码错误，无法登录 | | |
| TC004 | 管理员发布任务 | 1.管理员身份进入发布页面 2.填写完整任务信息 3.提交 | 任务发布成功，前端列表正常展示 | | |
| TC005 | 用户领取任务 | 1.普通用户进入任务列表 2.点击领取空闲任务 | 任务状态变更为已领取，本人可见 | | |
| TC006 | 用户提交任务 | 1.进入已领取任务 2.填写完成内容提交 | 任务状态变更为待审核 | | |
| TC007 | 管理员审核通过 | 1.管理员打开待审核任务 2.点击审核通过 | 任务状态变为已完成，用户收到结果 | | |
| TC008 | 管理员审核驳回 | 1.管理员打开待审核任务 2.填写驳回理由驳回 | 任务退回用户，可重新提交 | | |
| TC009 | 越权访问后台 | 普通用户直接输入管理员后台地址 | 自动拦截，禁止访问 | | |
| TC010 | 空表单提交 | 所有输入框留空直接提交 | 友好提示禁止空提交，数据不传入 | | |
