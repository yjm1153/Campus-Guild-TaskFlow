## 一、项目概述

### 1. 项目背景

校园内各类社团、学生组织在任务管理中普遍存在信息流失快、匹配效率低、缺乏激励机制等痛点。本项目针对校园场景下的轻量化任务协作需求，引入 RPG 游戏中的"冒险者公会"模式，将互助行为转化为"发布悬赏"与"接取任务"，通过虚拟积分流转与等级成长机制，构建高效、透明且自带激励属性的校园互助生态。

### 2. 系统目标

- 实现用户注册登录、JWT 身份认证，区分管理员与普通用户角色。
- 实现任务悬赏市场：发布/浏览/接取/完成/取消/放弃全流程管理。
- 实现积分与等级成长体系：完成任务获得积分和经验值，升级增强参与感。
- 实现管理员后台：数据统计、用户管理（封禁/解封）、任务管理（删除）。
- 实现前后端分离架构，前端通过 GitHub Actions 自动部署至 GitHub Pages。

### 3. 开发环境

## 二、需求分析

### 1. 核心模块

**用户与权限管理模块**

- 用户注册、登录、退出登录，密码 BCrypt 加密存储。
- 基于 JWT 令牌的身份认证，未登录返回 401。
- 管理员（admin 账号）可封禁/解封用户，管理全部任务。

**任务悬赏市场模块**

- 用户发布悬赏任务，填写标题、分类、描述、悬赏积分、任务期限。
- 发布时冻结积分，积分不足禁止发布。
- 任务大厅展示待接取任务，支持关键词搜索（300ms 防抖）和分类筛选。
- 接取采用乐观锁防并发，不能接取自己的任务。
- 任务状态流转：待接取 → 进行中 → 已完成 / 已取消。
- 发布者确认完成后悬赏积分转给接取者；发布者可取消未完成任务（退还积分）。
- 接取者可主动放弃已接取任务，任务回到待接取状态。
- 过期任务由定时调度器自动取消并退还积分。

**积分与等级模块**

- 发布时扣除积分，完成时获得积分和经验值（经验值 = 赏金 × 10）。
- 每 100 经验值升 1 级，等级在个人中心展示。

**管理模块**

- 系统统计看板：用户总数、任务总数、各状态分布。
- 用户管理：分页列表、封禁/解封。
- 任务管理：按状态筛选、分页列表、删除异常任务。

### 2. 非功能需求

- 支持 50 人同时在线，页面响应 ≤ 2s。
- 密码 BCrypt 加密，JWT 校验，核心接口防未授权访问。
- 兼容 Chrome / Edge / Firefox，PC 端与移动端双适配。
- 代码推送自动触发 GitHub Actions 构建部署。

## 四、系统实现

### 1. 功能实现

**用户认证（JWT）**

- AuthController 提供 register/login/logout/me 四个端点。
- 登录成功后返回 JWT 令牌（24 小时有效期），前端存入 localStorage。
- 退出登录时令牌加入内存黑名单，阻止复用。
- AuthUtil.requireUserId() 统一提取当前用户，未登录返回 401。

**任务发布与接取**

- 发布时校验积分余额 → 创建任务（状态 PENDING） → 扣除发布者积分。
- 接取时使用乐观锁：`UPDATE tasks SET status=?, accepter=? WHERE id=? AND status='PENDING'`。
- 状态流转在 Service 层严格校验，防止非法的状态跳转。

**积分结算**

- PointsService：deductPoints（发布冻结）、settleReward（完成结算）、refundPoints（取消退还）。
- 完成时接取者获得赏金 + 经验值（赏金 × 10），每 100 经验升 1 级。

**定时任务**

- TaskExpirationScheduler 每整点扫描 IN_PROGRESS 和 PENDING 过期任务。
- 过期任务自动取消，退还发布者积分。

**前端 SPA**

- app.js 约 1100 行，实现客户端路由、模板渲染、事件委托。
- 状态管理：全局 state 对象包含当前页面、用户信息、任务列表、分页状态等。
- 搜索防抖（300ms）、操作锁（actionLoading）、分页控件。

### 2. UI 页面

1. **登录/注册页**：校园风格表单，输入校验实时提示。
2. **任务大厅**：搜索栏 + 分类筛选 + 任务卡片网格 + 分页。
3. **任务详情**：完整信息 + 身份相关操作按钮（接取/完成/取消/放弃）。
4. **发布悬赏**：标题/分类/描述/积分（含快捷预设）/期限输入。
5. **个人中心**：头像/昵称/积分/经验等级进度条/我发布/我接取（分页）。
6. **管理面板**：统计看板 + 用户管理 + 任务管理。

### 3. 核心代码片段

**任务接取乐观锁（TaskRepository）**

```java
@Modifying(clearAutomatically = true)
@Query("UPDATE Task t SET t.status = :status, t.accepter = :accepter 
 WHERE t.id = :taskId AND t.status = :expectedStatus")
int tryAccept(@Param("taskId") Long taskId, @Param("accepter") User accepter,
              @Param("status") TaskStatus status,
              @Param("expectedStatus") TaskStatus expectedStatus);
```

**积分结算逻辑（PointsService）**

```java
@Transactional
public void settleReward(User accepter, int reward) {
    accepter.setPoints(accepter.getPoints() + reward);
    int expGain = reward * 10;
    accepter.setExperience(accepter.getExperience() + expGain);
    int newLevel = (accepter.getExperience() / 100) + 1;
    if (newLevel > accepter.getGuildLevel()) {
        accepter.setGuildLevel(newLevel);
    }
    userRepository.save(accepter);
}
```

## 六、用户手册

### 1. 安装部署

**后端：**
1. 安装 JDK 17。
2. 开发环境：H2 零配置，直接启动。
3. 生产环境：配置 MySQL，执行 `sql/schema.sql`，设置环境变量 `JWT_SECRET` 和 `DB_PASSWORD`。
4. 启动：`.\mvnw.cmd spring-boot:run`（端口 8080）。
5. Swagger UI：`http://localhost:8080/swagger-ui.html`（仅开发环境启用）。

**前端：**
1. 本地运行：打开 `ui/index.html`。
2. 生产构建：`npx esbuild js/app.js --bundle --outfile=js/bundle.js --minify`。
3. GitHub Pages：推送后自动构建部署。

### 2. 操作指南

**普通用户流程：**
1. 注册账号 → 登录系统。
2. 进入"任务大厅"浏览任务，搜索或按分类筛选，点击任务查看详情。
3. 点击"接取任务"，任务进入进行中状态。
4. 完成任务后等待发布者确认，获得积分和经验值。
5. 如需放弃已接取任务，在详情页点击"放弃任务"。
6. 在"个人中心"查看积分、经验、等级及历史任务。

**发布任务流程：**
1. 点击"发布悬赏"，填写任务信息。
2. 选择分类，设定悬赏积分（可用 10/20/50 快捷预设）和任务期限（1-90 天）。
3. 提交后系统冻结相应积分。
4. 待接取时可取消（退还积分）；进行中时可确认完成。

**管理员流程：**
1. 使用 admin/admin123 登录（生产环境建议修改密码）。
2. 查看统计看板，监控系统运行状态。
3. 用户管理：封禁违规用户。
4. 任务管理：删除异常任务（待接取状态退还积分）。
