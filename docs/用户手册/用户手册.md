# 校园公会任务流系统 用户手册
## 一、安装部署说明
### （一）后端部署步骤
1.  环境准备：安装JDK 17、Maven、MySQL 8.0，确保环境变量配置正确。
2.  数据库配置：执行sql目录下的init.sql脚本，创建数据库与数据表；修改server/resources/application.yml中的数据库连接信息（用户名、密码、数据库地址），确保与本地MySQL配置一致。
3.  项目打包：进入server目录，打开命令行，执行mvn clean package命令，打包生成jar包（位于target目录下）。
4.  启动服务：执行命令java -jar campus-guild-taskflow.jar，启动后端服务，默认端口为8080，启动成功后可通过localhost:8080访问接口。
### （二）前端部署步骤
1.  本地运行：直接打开ui目录下的index.html文件，即可访问前端页面，自动关联本地后端接口。
2.  GitHub Pages部署：将前端代码推送到GitHub仓库main分支，GitHub Actions会自动触发deploy.yml工作流，完成前端静态资源构建与部署，部署完成后可通过仓库Pages链接访问系统。
## 二、操作指南
### （一）用户注册与登录
1.  访问系统首页，点击"注册"按钮，进入注册页面，填写用户名、密码、真实姓名，点击"注册"完成账号创建（用户名唯一，密码长度不小于6位）。
2.  注册成功后，自动跳转至登录页面，输入注册的用户名和密码，点击"登录"，获取JWT令牌并进入系统首页。
3.  登录后，点击页面右上角"退出登录"，可退出系统，清除当前登录状态。
### （二）管理员操作流程
1.  登录系统后，进入"公会管理"页面，点击"创建公会"，填写公会名称、公会简介，点击"确认"完成公会创建。
2.  进入"成员管理"页面，输入用户名，点击"邀请加入"，将普通用户添加至公会；可查看所有公会成员，对违规成员进行封禁/解封操作。
3.  进入"任务管理"页面，点击"创建任务"，填写任务标题、描述、分类、悬赏积分、任务期限，选择任务接收成员，点击"发布"，冻结对应积分并发布任务。
4.  进入"任务审核"页面，按状态筛选待审核任务，查看任务提交结果，点击"通过"完成审核（积分自动结算给接取者），或点击"驳回"并填写驳回意见，任务状态更新为"已驳回"。
5.  进入"数据统计"页面，查看系统统计数据（用户总数、任务总数、各状态分布）及成员任务完成率，掌握系统运行情况。
### （三）普通成员操作流程
1.  登录系统后，进入"任务大厅"，可通过关键词搜索、分类筛选，浏览所有待接取任务（无法接取自己发布的任务）。
2.  点击任务标题，查看任务详情，确认可完成后，点击"接取任务"，任务状态更新为"进行中"。
3.  完成任务后，进入"我的任务"页面，找到对应进行中任务，点击"提交任务"，上传任务结果，任务状态更新为"已提交"。
4.  若任务被驳回，在"我的任务"页面查看驳回意见，修改任务结果后重新提交。
5.  进入"个人中心"页面，查看个人信息、积分、经验值与等级，可修改个人昵称等基础信息。
